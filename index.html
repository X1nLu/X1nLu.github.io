CSS 加载动画合集

12 种纯 CSS 实现 · 零外部依赖 · 可直接复制使用

Keyframes + Transform GPU 加速 prefers-reduced-motion 降级

旋转圆环

经典边框旋转加载器，通过 border-top 颜色差异配合 rotate 实现无限旋转。

/* 旋转圆环 */
.ring-loader {
  width: 48px;
  height: 48px;
  border: 4px solid rgba(129, 140, 248, 0.2);
  border-top-color: #818cf8;
  border-radius: 50%;
  animation: ring-spin 0.8s linear infinite;
  will-change: transform;
}

@keyframes ring-spin {
  to { transform: rotate(360deg); }
}

@media (prefers-reduced-motion: reduce) {
  .ring-loader { animation: none; }
}

脉冲圆点

三个圆点依次缩放脉动，通过 animation-delay 制造错峰节奏，营造"呼吸感"。

/* 脉冲圆点 */
.pulse-dots {
  display: flex;
  gap: 10px;
}
.pulse-dots span {
  width: 14px;
  height: 14px;
  border-radius: 50%;
  background: #818cf8;
  animation: dot-pulse 1.4s ease-in-out infinite;
  will-change: transform, opacity;
}
.pulse-dots span:nth-child(2) { animation-delay: 0.2s; }
.pulse-dots span:nth-child(3) { animation-delay: 0.4s; }

@keyframes dot-pulse {
  0%, 80%, 100% { transform: scale(0.6); opacity: 0.4; }
  40%           { transform: scale(1);   opacity: 1; }
}

@media (prefers-reduced-motion: reduce) {
  .pulse-dots span { animation: none; opacity: 0.7; }
}

渐变锥形旋转器

利用 conic-gradient 生成锥形渐变，配合 radial-gradient mask 镂空成环，旋转产生拖尾。

/* 渐变锥形旋转器 */
.conic-spinner {
  width: 50px;
  height: 50px;
  border-radius: 50%;
  background: conic-gradient(from 0deg, #ec4899, #818cf8, transparent 70%);
  -webkit-mask: radial-gradient(farthest-side, transparent calc(100% - 5px), #000 calc(100% - 4px));
  mask: radial-gradient(farthest-side, transparent calc(100% - 5px), #000 calc(100% - 4px));
  animation: conic-spin 1s linear infinite;
  will-change: transform;
}

@keyframes conic-spin {
  to { transform: rotate(360deg); }
}

@media (prefers-reduced-motion: reduce) {
  .conic-spinner { animation: none; }
}

骨架屏微光

内容占位线上的高光从左到右扫过，伪元素 ::after 配合 translateX 实现 GPU 加速扫光。

/* 骨架屏微光 */
.skeleton-shimmer {
  width: 130px;
}
.skeleton-shimmer .sk-line {
  height: 12px;
  border-radius: 5px;
  background: #25253a;
  position: relative;
  overflow: hidden;
  margin-bottom: 10px;
}
.skeleton-shimmer .sk-line:last-child {
  margin-bottom: 0;
  width: 65%;
}
.skeleton-shimmer .sk-line::after {
  content: '';
  position: absolute;
  inset: 0;
  background: linear-gradient(90deg, transparent, rgba(129, 140, 248, 0.4), transparent);
  transform: translateX(-100%);
  animation: shimmer-slide 1.6s ease-in-out infinite;
  will-change: transform;
}

@keyframes shimmer-slide {
  100% { transform: translateX(100%); }
}

@media (prefers-reduced-motion: reduce) {
  .skeleton-shimmer .sk-line::after { display: none; }
}

DNA 双螺旋

七根渐变横条以 rotateY 3D 旋转，错峰延迟产生螺旋扭转效果，呈现双链交叉视错觉。

.dna-helix {

  height: 64px;
  display: flex;
  flex-direction: column;
  justify-content: space-between;
  perspective: 100px;

.dna-helix .rung {
  height: 3px;
  width: 100%;
  background: linear-gradient(90deg, #a78bfa 0%, #a78bfa 15%, #f472b6 85%, #f472b6 100%);
  border-radius: 2px;
  animation: dna-rotate 2s linear infinite;
  transform-style: preserve-3d;
  will-change: transform;
}
.dna-helix .rung:nth-child(1) { animation-delay: 0s; }
.dna-helix .rung:nth-child(2) { animation-delay: -0.2s; }
.dna-helix .rung:nth-child(3) { animation-delay: -0.4s; }
.dna-helix .rung:nth-child(4) { animation-delay: -0.6s; }
.dna-helix .rung:nth-child(5) { animation-delay: -0.8s; }
.dna-helix .rung:nth-child(6) { animation-delay: -1s; }
.dna-helix .rung:nth-child(7) { animation-delay: -1.2s; }

@keyframes dna-rotate {
  0%   { transform: rotateY(0deg); }

@media (prefers-reduced-motion: reduce) {
  .dna-helix .rung { animation: none; }
}
